
# Backend — EduMath

Серверная часть рекомендательной системы образовательных курсов.

## Технологии

- Python
- FastAPI
- Uvicorn

## Запуск

1. Перейти в папку backend:

    cd backend

2. Установить зависимости:

    py -m pip install -r requirements.txt

3. Запустить сервер:

    py -m uvicorn main:app --reload

4. Открыть документацию API:

    http://127.0.0.1:8000/docs

## API


### GET /courses

Возвращает список доступных курсов.

Поддерживает поиск и фильтрацию:

- `/courses` — все курсы.
- `/courses?search=Python` — поиск по названию.
- `/courses?category=Программирование` — фильтрация по категории.
- `/courses?search=Python&category=Программирование` — поиск и фильтрация одновременно.

Поиск не зависит от регистра букв.
Если подходящих курсов нет, возвращается пустой список.


Возвращает список доступных курсов.

### GET /recommendations?user_id=1

Возвращает 10 рекомендаций для пользователя.

Каждая рекомендация содержит:
- course_id — ID курса
- title — название курса
- category — категория курса
- score — оценка рекомендации

## Запуск через Docker

Перейти в папку backend:

```powershell
cd backend
```

Собрать Docker-образ:

```powershell
docker build -t edumath-backend .
```

Запустить контейнер:

```powershell
docker run --rm -p 8000:8000 --name edumath-api edumath-backend
```

После запуска документация API доступна по адресу:

http://127.0.0.1:8000/docs

Для остановки контейнера нажать Ctrl + C.

## CORS

Backend разрешает обращения с локальных адресов Frontend:
- http://localhost:3000
- http://127.0.0.1:3000
- http://localhost:5173
- http://127.0.0.1:5173

После согласования с Frontend список адресов можно изменить.
