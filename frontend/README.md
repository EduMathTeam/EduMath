# EduMath — Frontend (React + Vite)

Первая версия интерфейса. Использует существующие Backend API:
- `GET /courses` — массив `{course_id, title, category}`
- `GET /recommendations?user_id=1` — массив `{course_id, title, category, score}`

## Запуск

Понадобится Node.js 18+ (рекомендуется 20 LTS).

1. Запустите Backend на `http://127.0.0.1:8000` по инструкции `backend/README.md`.
2. В этой папке (`frontend/`) выполните:

```bash
npm install
npm run dev
```

3. Откройте `http://127.0.0.1:5173`.

Если Backend по другому адресу, создайте файл `.env` по примеру `.env.example`, укажите `VITE_API_BASE_URL`, перезапустите Vite.

## Уже работает

- Каталог курсов через реальный API, адаптивные карточки.
- Поиск и фильтрация по категориям на клиенте (работают даже пока PR с серверными фильтрами не слит).
- Отдельная страница рекомендаций; смена `user_id` вызывает API.
- Состояния загрузки, пустой выдачи, ошибки соединения и кнопка повторной попытки.

## Пока не реализовано

- Реальное ML (зависит от Backend/ML участника).
- Оценки, избранное и пользовательские профили (для этого ещё нет согласованных API).
- Страница конкретного курса (нет `GET /courses/{id}`).
- Реальные изображения курсов (используются декоративные цветные обложки).

Важно: `score` — оценка алгоритма, а не гарантированная вероятность или процент соответствия.
