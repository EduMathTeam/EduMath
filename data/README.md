# Data
# Подготовка данных

Папка содержит исходные данные, инструменты для их анализа и подготовки, а также результаты предварительного аудита датасета для проекта рекомендательной системы образовательных курсов.

## Используемые технологии

- Python 3
- pandas

## Структура папки

```text
data/
├── raw/                  # Исходные CSV-файлы
├── processed/            # Обработанные данные
├── src/                  # Скрипты для анализа и подготовки данных
│   └── data_audit.py     # Скрипт предварительного аудита датасета
├── README.md
├── requirements.txt
└── .gitignore
```

## Источник данных

В проекте используется датасет OpenEdu Courses с платформы Hugging Face:

`pymlex/openedu-courses`

Исходные файлы:
- `openedu_courses_base_info.csv` — основная информация о курсах.
- `openedu_courses_full_info.csv` — расширенная информация о курсах.
- `openedu_groups_map.csv` — справочник образовательных направлений.

## Установка зависимостей

Из корневой папки проекта выполните:

```bash
pip install -r data/requirements.txt
```

## Запуск аудита данных

Из корневой папки проекта:

```bash
python data/src/data_audit.py
```

Скрипт проверяет структуру датасета, пропущенные значения, дубликаты, типы данных, образовательные направления, числовые и текстовые поля, а также даты.
