# Data Engineering

Директория `data/` содержит исходные и обработанные данные, а также инструменты для их анализа и подготовки в рамках проекта EduMath.

Основной источник данных — набор образовательных курсов OpenEdu.

## Структура директории

```text
data/
├── raw/
│   ├── openedu_courses_base_info.csv
│   ├── openedu_courses_full_info.csv
│   └── openedu_groups_map.csv
│
├── processed/
│   └── courses.csv
│
├── src/
│   ├── data_audit.py
│   └── prepare_courses.py
│
├── README.md
├── requirements.txt
└── .gitignore
```

## Содержимое

### raw/

Исходные CSV-файлы набора OpenEdu:

- `openedu_courses_base_info.csv` — основная информация о курсах.
- `openedu_courses_full_info.csv` — расширенная информация о курсах.
- `openedu_groups_map.csv` — справочник образовательных направлений.

Исходные файлы используются как источник данных и не изменяются при обработке.

### processed/

Содержит подготовленные наборы данных.

- `courses.csv` — таблица курсов, предназначенная для дальнейшего использования компонентами ML и Backend.

### src/

Python-скрипты для работы с данными:

- `data_audit.py` — анализ структуры и качества исходных данных.
- `prepare_courses.py` — преобразование исходных данных и формирование обработанного датасета.

## Структура courses.csv

Файл `processed/courses.csv` содержит следующие поля:

| Поле | Описание |
|---|---|
| `course_id` | Идентификатор курса из исходного датасета |
| `title` | Название курса |
| `category` | Основная категория курса |
| `description` | Описание курса |
| `university` | Университет |
| `language` | Язык курса |
| `directions` | Направления курса, разделённые символом `;` |

**Особенности полей:**

- `course_id` сохраняет исходный идентификатор курса.
- `category` определяется по наиболее часто встречающемуся направлению среди направлений конкретного курса.
- `directions` содержит все найденные направления курса в виде строки.
- Если в исходных данных направления отсутствуют, `category` и `directions` остаются пустыми.

Текущая структура `courses.csv` является рабочей версией и может корректироваться после согласования с ML- и Backend-компонентами.

## Используемые технологии

- **Python 3** — язык программирования.
- **pandas** — загрузка, анализ и обработка табличных данных.
- **collections.Counter** — подсчёт частоты образовательных направлений.
- **pathlib** — работа с путями к файлам и директориям.

## Установка зависимостей

Из корневой директории проекта:

```bash
pip install -r data/requirements.txt
```

## Запуск скриптов

Проверка исходных данных:

```bash
python data/src/data_audit.py
```

Подготовка обработанного датасета:

```bash
python data/src/prepare_courses.py
```

После выполнения `prepare_courses.py` результат сохраняется в `data/processed/courses.csv`.
